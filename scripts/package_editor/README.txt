Bernini Editor {version}

A beta build for trying the editor, not a release. Expect rough edges, and report them.

Run editor.exe from this folder. It is unsigned, so SmartScreen may ask first: choose More info,
then Run anyway. Keep the folder together: the editor reads its shaders, assets and plugins from
beside itself, and writes editor.log there.

Requires 64-bit Windows 10 or 11 with a DirectX 12 GPU.
